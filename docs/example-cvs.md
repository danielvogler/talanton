# Example CVs

**Invented people. Every name, employer, address and date here is fictional.**
They exist so the whole pipeline can be run and tested without a mailbox, real
credentials, or anybody's actual application.

They live in [`example/cvs/`](../example/cvs/), one folder per opening — which
is the point: two postings never share a pile of CVs.

```bash
talanton --config example/talanton.toml status
talanton --config example/talanton.toml next 101
```

The PDFs are generated by
[`scripts/build_example_cvs.py`](../scripts/build_example_cvs.py) rather than
committed as opaque binaries, so the layouts are reviewable and reproducible:

```bash
uv run python scripts/build_example_cvs.py
```

## Opening 101 — AI Engineer

| File | Format | What it is for |
|---|---|---|
| `rossi-marco.txt` | text | A strong candidate. Should score well and clear every knockout. |
| `chen-wei.txt` | text | Solid but narrower — owned a component, not a system. Should rank below Rossi. |
| `keller-nadia.pdf` | PDF | **A modern layout**: right-aligned date rail, section rules, a three-column skills grid. |
| `andersson-lars.pdf` | PDF | **A two-column layout** with a sidebar — where naive extraction loses the contact details. Also **fails a knockout**: no work permit. The filter must hold him back however well he reads. |
| `dubois-camille.pdf` | PDF | **An academic layout**: serif face, en-dash year ranges, a publications list. Research only, no commercial deployment — the rubric caps the production score, which tests that the rubric is applied rather than the CV's polish. |
| `injection-attempt.pdf` | PDF | Instructions addressed to the model, in the format one would really arrive in. The screener has no tools, so it cannot act on them; it should flag `prompt-injection-attempt` and assess the document as written. |
| `scanned-cv.pdf` | PDF | Image-only, no text layer. Must be reported **unreadable**, never scored zero — that failure would be invisible and would cost a real person a job. |
| `not-a-cv.txt` | text | Too short to assess. Should be reported, not guessed at. |

## Opening 102 — Data Engineer

Exists so the examples show why openings are numbered at all: a second posting,
with its own rubric, its own apply address and its own drawer of CVs.

| File | Format | What it is for |
|---|---|---|
| `okonkwo-ada.pdf` | PDF | **A header band and prose rather than bullets**, with `MM/YYYY` dates. |
| `fernandez-mateo.pdf` | PDF | **Abbreviated year ranges** (`'21–now`), a projects section, a two-column footer. Needs a permit but is EU, so the knockout turns on how the rubric is worded. |

If you add one, say here what it exercises. A CV that tests nothing is just
noise in the fixtures.
